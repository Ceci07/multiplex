# In silico assessment of primers targeting different AMR gene families
An R script compared ABRicate detections from in silico-predicted amplicons using literature primers, with those obtained from whole-genome sequences, which were used as the reference, at the sample-by-panel-target level. The script mapped detected alleles to the theoretical panel targets, calculated overall and target-specific sensitivity and precision, identified recovered and missed targets, and reported genes detected by WGS that were outside the panel.  

In silico amplicons can be detected with ≥85% sensitivity and ≥95% specificity.  

![alt text](https://github.com/Ceci07/multiplex/blob/main/insilico_amplicons.png)

CTX-M-family detection is high, however CTX-M-15 was generally called as CTX-M-139, CTX-M-14 as CTX-M-104, and CTX-M-27 as CTX-M-174 (not shown). Since CTX-M-15 has the greatest epidemiological relevance and is globally disseminated and strongly associated with pandemic _E. coli_ lineages such as ST131. Efforts to optimize the detection of relevant alleles such as CTX-M-15 for error-prone long-read sequencing is required.
